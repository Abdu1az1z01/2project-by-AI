# AI-помощник для компьютера

Автономный помощник на базе Claude: работает **только** с теми папками и программами, которые вы разрешили. Он сам следит за изменениями, анализирует их и принимает решения без вашего участия.

## Как это работает

```
 ┌──────────── автономный цикл (каждые N секунд) ─────────────┐
 │  Observer (sensors.py)  → новые/изменённые файлы,           │
 │                           нагрузка на CPU/память/диск       │
 │        │ есть события?                                      │
 │        ▼                                                    │
 │  Agent (agent.py) ← цели + долговременная память            │
 │        │ Claude думает и вызывает инструменты               │
 │        ▼                                                    │
 │  ToolBox (tools.py) → Sandbox проверяет КАЖДЫЙ путь/команду │
 │        │ результат (или ошибка) возвращается Claude,        │
 │        └─ он адаптирует план и продолжает                   │
 └─────────────────────────────────────────────────────────────┘
```

* **Песочница.** Все пути проходят через `Sandbox` (`assistant/config.py`): `..` и символические ссылки раскрываются, доступ есть только внутри `read_roots`/`write_roots`, а пути из `deny_patterns` (ключи, пароли, `.ssh`…) заблокированы всегда.
* **Команды.** Можно запускать только программы из `allowed_commands`, без оболочки. Символы `|`, `>`, `&&`, `$` запрещены.
* **Обратимость.** Помощник ничего не удаляет насовсем: удалённые и перезаписанные файлы попадают в `~/.ai-assistant/trash/`.
* **Журнал.** Каждое действие записывается в `~/.ai-assistant/audit.jsonl`.
* **Память.** Заметки помощника хранятся в `~/.ai-assistant/memory.md` и передаются ему в каждом цикле, поэтому он постепенно подстраивается под вас.
* **Предохранители.** Есть лимит действий за цикл и циклов в час. Файл `~/.ai-assistant/STOP` ставит работу на паузу, `Ctrl+C` останавливает её.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp config.example.yaml config.yaml # Windows: copy config.example.yaml config.yaml
# отредактируйте config.yaml: какие папки и программы доступны, какие у помощника цели

export ANTHROPIC_API_KEY=sk-ant-...   # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
```

API-ключ можно получить на https://platform.claude.com.

## Запуск

```bash
python -m assistant chat          # диалог: вы даёте задачи, а изменения подтверждаете (y/N)
python -m assistant auto --once   # один автономный цикл: осмотреться и составить план
python -m assistant auto          # постоянная работа в фоне
```

Примеры задач в режиме `chat`:
* «Разбери папку Загрузки по типам файлов»
* «Найди все PDF со словом "договор" в Документах»
* «Почему ноутбук тормозит?»

## Голосовой режим

Вы говорите вслух, помощник отвечает голосом. Пока вы молчите, он сам следит за компьютером и подсказывает, если что-то произошло: появился новый файл, заполнился диск, какая-то программа грузит процессор.

```bash
pip install -r requirements-voice.txt
python -m assistant voice
```

* Говорите обычной речью: «Что у меня в загрузках?», «Посоветуй, как лучше подготовиться к IELTS», «Почему ноутбук тормозит?».
* Перед изменением файлов помощник спрашивает вслух. Ответьте «да» или «нет».
* Чтобы завершить, скажите «выход» или нажмите Ctrl+C.
* Если в `config.yaml` задать `voice.wake_word: "помощник"`, он будет реагировать только на фразы с этим словом («Помощник, какая нагрузка на процессор?»). Это полезно, когда рядом разговаривают другие люди.
* Речь распознаёт сервис Google, поэтому нужен интернет. Озвучка работает через голоса Windows. Если голос говорит с английским акцентом, установите русский речевой пакет: Параметры → Время и язык → Речь → Добавить голоса → Русский.

## Советы по безопасности

1. Начните с узкого доступа: одна-две папки и `confirm_in_chat: true`.
2. Не добавляйте в `allowed_commands` программы, которые могут выполнить произвольный код (`python`, `powershell`, `bash`), если не готовы к этому. Через них помощник может выйти за пределы песочницы.
3. Не включайте в `read_roots` всю домашнюю папку целиком.
4. Время от времени просматривайте `audit.jsonl` и `notifications.log`.

## Структура

| Файл | Назначение |
|---|---|
| `assistant/config.py` | загрузка настроек, песочница путей |
| `assistant/tools.py` | инструменты (файлы, поиск, команды, система, память, уведомления) |
| `assistant/sensors.py` | наблюдение за файлами и нагрузкой в реальном времени |
| `assistant/agent.py` | цикл работы Claude с инструментами, автономный анализ |
| `assistant/voice.py` | микрофон, распознавание речи, озвучка ответов |
| `assistant/__main__.py` | режимы `chat`, `auto` и `voice` |
